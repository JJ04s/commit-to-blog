# 학습용 흐름 중심 코드 분석 지침 (Code Learning Analyzer)

이 스킬은 사용자가 자신의 코드를 복기하고 학습하기 위해, 커밋 변경 사항에서 기술적 통찰과 구현 원리를 **서사적 흐름(Flow)** 중심으로 추출하는 데 사용됩니다.

## 1. 핵심 분석 구조 (Logical Flow)
단순한 기능 나열이 아닌, 다음의 흐름을 가진 하나의 '기술 서사'를 구성해야 합니다:

1.  **배경 및 기반 (Foundation):** 
    *   왜 이 작업이 시작되었는지(문제 제기), 어떤 기술적 전제 조건이나 배경 지식이 필요한지 설명합니다.
2.  **구현 접근 방식 및 전개 (Approach):** 
    *   **능동적 브릿징(Logical Bridging)**: 단순히 코드 변경을 나열하지 말고, 특정 코드 수정이 왜 목표 달성을 위해 필요한지 그 사이의 인과관계를 설명합니다.
    *   **도입 기술의 원리**: 사용된 라이브러리/스택의 핵심 원리가 구현에 어떻게 녹아들었는지 상세히 분석합니다.
3.  **심화 및 결론 (Convergence):** 
    *   구현된 결과가 시스템에 어떤 가치를 더하는지, 그리고 이 과정을 통해 얻은 최종적인 기술적 결론을 제시합니다.

## 2. 분석 원칙
- **흐름 중심 요약**: 세부 수치나 지엽적인 코드보다는 전체적인 **'논리적 전개 방식'**에 집중합니다.
- **도약 없는 설명**: 사용자가 배경 지식을 완벽히 공유하지 않더라도 이해할 수 있도록, 로직 사이의 공백을 표준적인 기초 원리로 메워 설명합니다.
- **핵심 코드 스니펫**: 논리적 전개를 뒷받침하는 결정적인 코드 조각을 발췌하여 분석합니다.

## 3. 출력 형식 (Output Format)
응답은 반드시 아래의 JSON 스키마를 준수해야 합니다:
```json
{
  "title": "학습 회고: [논리적 흐름의 핵심 키워드]",
  "content": "마크다운 형식의 흐름 중심 분석 본문",
  "tags": ["기술스택", "논리구조", "학습포인트"]
}
```
